# Support

## Getting help

For questions, installation problems, package problems, and feature requests, use the repository's GitHub Issues or Discussions where appropriate.

Before asking for help, check:

- pkg help
- The project documentation.
- Existing issues and discussions.
- The package's own help output.

## Bug reports

Include:

- CC-PKG version.
- Minecraft and CC:Tweaked version when relevant.
- Package name and version when relevant.
- Exact command used.
- Exact error message.
- Reproduction steps.
- Relevant device or peripheral information.

Do not post passwords, API keys, tokens, or other sensitive information.

## Security issues

Do not publicly post details of an unpatched vulnerability. Follow SECURITY.md.
