# Code of Conduct

## Our commitment

Cubes Studio is committed to maintaining a welcoming, respectful, and constructive community around CC-PKG.

Everyone participating in this project is expected to contribute in a way that supports collaboration, learning, creativity, and technical discussion.

## Expected behavior

Participants are expected to:

- Treat other people with respect and courtesy.
- Give constructive feedback focused on the project, code, documentation, or ideas.
- Credit other people's work when using or building upon it.
- Respect different levels of experience and perspectives.
- Keep discussions relevant and productive.
- Report security issues responsibly rather than intentionally exploiting them against other contributors.

## Unacceptable behavior

The following is not acceptable:

- Harassment, threats, intimidation, or targeted abuse.
- Discrimination or hateful conduct.
- Personal attacks or deliberate humiliation.
- Doxxing or publishing private information without permission.
- Spam, malicious content, or deliberate disruption.
- Impersonation of Cubes Studio, maintainers, or contributors.
- Removing or falsifying required attribution or credits.
- Knowingly submitting malicious code, malware, or intentionally harmful changes.

## Moderation

Maintainers may remove content, close discussions, reject contributions, restrict participation, or take other reasonable moderation actions when this Code of Conduct is violated or project spaces are materially disrupted.

## Reporting

Report conduct violations privately to the project maintainers through the contact method provided by the repository.

For security vulnerabilities, use SECURITY.md rather than publicly posting exploit details.

## Scope

This Code of Conduct applies to issues, pull requests, discussions, documentation, repository contributions, and other project spaces associated with CC-PKG.

## Enforcement

Reports will be reviewed and handled as privately as reasonably possible. This Code of Conduct does not replace GitHub policies or applicable law.
